# Security

Please report a vulnerability privately, either way:

- Email **contact@roadtokickoff.com** with `tz-at-point` in the subject.
- Or open the repository's **Security** tab on GitHub and choose **Report a vulnerability**.

Don't open a public issue for it. You'll get a reply within a few days, and a fix or a published advisory before any details are made public.

Reports about the table validation in `createLookup`, the CLI's file handling, or anything that makes a lookup throw or return something other than a zone name are especially welcome.
